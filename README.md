# Student-Attendance-System-Using-Cameras
نظام متكامل يهدف إلى أتمتة عملية تحضير الطلاب وتسجيل حضورهم باستخدام تقنيات الرؤية الحاسوبية (Computer Vision) والتعرف على الوجوه. يعمل النظام على التقاط صور الطلاب عبر الكاميرا، مطابقتها بالبيانات المسجلة، وتسجيل الحضور فورياً في قاعدة البيانات، مما يوفر الوقت والجهد مقارنة بالطرق اليدوية التقليدية.
