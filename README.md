# Student Attendance System Using Cameras 📸🧑‍🎓

(نظام تحضير الطلاب الآلي باستخدام التعرف على الوجه)

## 📌 نبذة عن المشروع

نظام متكامل يهدف إلى أتمتة عملية تحضير الطلاب وتسجيل حضورهم باستخدام تقنيات الرؤية الحاسوبية (Computer Vision) والتعرف على الوجوه. يعمل النظام على التقاط صور الطلاب عبر الكاميرا، مطابقتها بالبيانات المسجلة، وتسجيل الحضور فورياً في قاعدة البيانات.

## ✨ المميزات الأساسية

* **تحضير فوري في الوقت الفعلي:** التعرف على وجوه الطلاب عبر الكاميرا وتسجيل حضورهم آلياً.
* **واجهة خلفية سريعة وفعالة:** مبنية باستخدام إطار عمل FastAPI لضمان سرعة معالجة الطلبات والصور.
* **إدارة متكاملة:** واجهة مستخدم (Frontend) مرنة لعرض لوحة التحكم، وإدارة بيانات الطلاب، ومتابعة سجلات الحضور.
* **تخزين آمن ومنظم:** الاعتماد على قاعدة بيانات SQL لحفظ السجلات وبيانات المستخدمين بشكل هيكلي.

## 🛠️ التقنيات والمكاتب المستخدمة

* **لغة البرمجة الأساسية:** Python
* **الواجهة الخلفية (Backend):** FastAPI, Uvicorn
* **الرؤية الحاسوبية (Computer Vision):** OpenCV
* **قاعدة البيانات:** SQL (مرفق ملف `student_attendance.sql`).
* **الواجهة الأمامية (Frontend):** HTML, JavaScript

## 🚀 خطوات التثبيت والتشغيل المحلي

### 1. تنزيل المشروع والدخول للمجلد (هام جداً)

بعد تنزيل المشروع (سواء عبر `git clone` أو كملف `ZIP` وفك ضغطه)، يجب عليك فتح موجه الأوامر (Terminal) والدخول إلى المجلد الرئيسي للمشروع قبل تنفيذ أي خطوة أخرى:

```bash
# استنساخ المشروع
git clone https://github.com/amjdsbyh358-ship-it/Student-Attendance-System-Using-Cameras.git

# الدخول إلى مجلد المشروع الرئيسي
cd Student-Attendance-System-Using-Cameras

```

*(ملاحظة: إذا قمت بتنزيل المشروع كملف ZIP، تأكد من الدخول إلى المجلد الذي يحتوي على ملف `requirements.txt` عبر أمر `cd`)*.

### 2. إنشاء وتفعيل البيئة الافتراضية

داخل المجلد الرئيسي للمشروع، قم بإنشاء البيئة الافتراضية الخاصة بك لتثبيت المكاتب بمعزل عن النظام:

```bash
# إنشاء البيئة الافتراضية
python -m venv venv

# تفعيل البيئة الافتراضية (لمستخدمي نظام ويندوز):
.\venv\Scripts\activate

# تفعيل البيئة الافتراضية (لمستخدمي نظام ماك/لينكس):
# source venv/bin/activate

```

### 3. تثبيت المكاتب المطلوبة

بعد تفعيل البيئة الافتراضية (ظهور كلمة `venv` في موجه الأوامر)، قم بتثبيت جميع المكاتب اللازمة لتشغيل النظام:

```bash
pip install -r requirements.txt

```

### 4. إعداد قاعدة البيانات والاتصال

* قم بإنشاء قاعدة بيانات جديدة في نظام إدارة قواعد البيانات لديك (مثل MySQL).
* قم باستيراد الملف المرفق `student_attendance.sql` لبناء الجداول الأساسية.
* تأكد من تعديل بيانات الاتصال الخاصة بقاعدة البيانات داخل ملف `.env` لتتوافق مع إعدادات جهازك.

### 5. تشغيل النظام

لتشغيل خادم الواجهة الخلفية، انتقل إلى مجلد `backend` واكتب أمر التشغيل:

```bash
cd backend -m uvicorn main:app --reload

```

بعد تشغيل السيرفر بنجاح، يمكنك فتح ملفات الواجهة الأمامية الموجودة في مجلد
```bash
cd frontend
python -m http.server 5500
من الموقع جوجل اكتب
http://localhost:5500/students.html
